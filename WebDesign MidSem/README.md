# AMA Community Information Board

## Overview

The **AMA Community Information Board** is a simple HTML project created to provide residents of Accra with important civic information and upcoming community events.

The project represents a digital notice board for the **Accra Metropolitan Assembly (AMA)** and promotes the motto:

> **"Working Together for a Better Accra"**

The webpage is designed to keep citizens informed about public programs, health campaigns, sanitation exercises, youth initiatives, and community meetings.

---

## Project Purpose

This project was created to:

- Improve communication between AMA and residents
- Display important civic announcements and events
- Encourage community participation
- Practice basic HTML webpage structure and content organization

---

## Features

The information board includes:

- AMA heading and official motto
- Introductory message for residents
- Four upcoming civic events:
  - Town Hall Meeting
  - Free Health Screening
  - Clean Accra Campaign
  - Youth Entrepreneurship Forum
- Footer section with copyright information

## How to View the Project

### Option 1: Open Directly in Browser

1. Download or copy the project folder to your computer
2. Open the folder
3. Double-click `ama.html`

The webpage will open in your default web browser.
